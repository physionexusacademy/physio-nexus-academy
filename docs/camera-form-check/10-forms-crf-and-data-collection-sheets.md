|---|---|---|---|---|---|---|
| 1 | I think that I would like to use this system frequently. | | | | | |
| 2 | I found the system unnecessarily complex. | | | | | |
| 3 | I thought the system was easy to use. | | | | | |
| 4 | I think that I would need the support of a technical person to be able to use this system. | | | | | |
| 5 | I found the various functions in this system were well integrated. | | | | | |
| 6 | I thought there was too much inconsistency in this system. | | | | | |
| 7 | I would imagine that most people would learn to use this system very quickly. | | | | | |
| 8 | I found the system very cumbersome to use. | | | | | |
| 9 | I felt very confident using the system. | | | | | |
| 10 | I needed to learn a lot of things before I could get going with this system. | | | | | |

Scoring: odd items score minus 1; even items 5 minus score; add and multiply by 2.5 (0 to 100).

*Roman Urdu draft of the SUS statements (a translated questionnaire should be checked by a fluent speaker and, ideally, back-translated before use; its scores are then described as from a translated version).* 1. Mere khayal mein main is system ko aksar istemal karna chahunga. 2. Mujhe system be-wajah pecheeda laga. 3. Mere khayal mein system istemal karna aasaan tha. 4. Mere khayal mein system istemal karne ke liye mujhe kisi technical shakhs ki madad chahiye hogi. 5. Mujhe system ke mukhtalif hisse aapas mein achhi tarah jude hue lage. 6. Mere khayal mein system mein bohat zyada be-tarteebi thi. 7. Mere khayal mein aksar log is system ko bohat jaldi seekh lenge. 8. Mujhe system istemal karna bohat mushkil laga. 9. Is system ko istemal karte hue main bohat pur-aitmaad tha/thi. 10. Is system ko shuru karne se pehle mujhe bohat kuch seekhna pada.

**Comfort items** (1 strongly disagree to 5 strongly agree): (a) I felt comfortable being in front of the camera. (b) The movements and the instructions were easy to follow. (c) I would be happy to use this at home.
